# 2B

## Overview

A Sperandeo swing-trading pattern: in an uptrend, price makes a marginal new high above a
prior peak, fails to carry through, and then drops back below the previous high — the
trend is apt to reverse. The mirror (2B bottom) forms when a second valley slightly
undercuts the first and price turns back up. Bulkowski views the 2B top as the start of a
double top that may never confirm.

## Identification Guidelines

| Characteristic | Guideline |
|---|---|
| Setup (top) | Uptrend makes a higher high above a prior peak but "fails to carry through" |
| Trigger (top) | Price drops below the previous high — then the trend is apt to reverse |
| Setup (bottom) | Converse: second valley near/below the first valley, then price turns up |
| Peak/valley proximity | Bulkowski's research used a second peak/valley within 5% of the first |
| Timing | Minor highs/lows: break within ~1 day; intermediate: 3–5 days; long-term turning points: 7–10 days |
| Width | Tops: median 10 days peak to peak; bottoms: median 21 days (study allowed up to a year) |
| Volume | Failure to carry forward usually on low/normal volume; reversal confirmation on higher volume |
| Best variation (top) | First peak below the second (marginal new high) → larger decline |
| Best variation (bottom) | First valley above the second (marginal new low) → larger rise |

## Detection Rules (computable)

2B top; the 2B bottom is the mirror image (swap highs/lows and inequalities).

Definitions: `peak1`, `peak2` = consecutive swing highs via `ta.pivothigh(l, r)` with
`peak2` after `peak1`.

- **R1 [D]** Prior uptrend: `close` at `peak1` above the close 20 bars earlier (default `N = 20`, adjustable).
- **R2 [B]** Second peak exceeds the first: `high_p2 > high_p1` (the marginal-new-high case is the classic 2B; Bulkowski's study also covers `high_p2 <= high_p1`).
- **R3 [B]** Peaks are near each other in price: `abs(high_p2 - high_p1) / high_p1 <= 0.05` (study window 5%).
- **R4 [D]** Peak separation: `2 <= (bar_p2 - bar_p1) <= 60` (median 10 days for tops; bounds are defaults).
- **R5 [B]** Failure to carry through / trigger: after `peak2`, `close < high_p1` (price drops back below the previous high).
- **R6 [D]** Timeliness of the trigger: the R5 close occurs within `10` bars of `peak2` (Sperandeo: 1–10 days depending on trend degree; default 10, adjustable).
- **R7 [D]** Optional volume filter: volume on the `peak2` advance ≤ its 20-bar SMA, and volume on the R5 trigger bar > its 20-bar SMA.

## Confirmation & Breakout

Trigger for a 2B top: a close back below the previous high (`close < high_p1`) after the
marginal new high — per Sperandeo, price must actually drop below the previous high or
it is not a valid 2B. For a 2B bottom: a close back above the previous low after the
marginal new low. Bulkowski notes the related unconfirmed double bottom fails 44% of the
time, so the early entry carries materially higher failure risk than waiting for full
double-top/bottom confirmation.

## Targets & Stops

- No measure rule stated. Reference magnitudes from the study [B]: tops — median decline
  7% from the second peak's high (benchmark for all peaks: 10%); bottoms — average gain
  ~33% from the second bottom's low (benchmark for all bottoms: 34%).
- Default target [D]: `target = high_p2 * (1 - 0.07)` for tops / `low_v2 * (1 + 0.33)`
  for bottoms, or manage the swing with a trailing stop.
- Stop [D]: just above the second peak (`high_p2 * (1 + 0.005)`) for shorts; just below
  the second valley for longs.

## Performance

Tops (41,702 samples, 468 stocks, 2010–2020):

| Metric | Value |
|---|---|
| Median decline, all samples | 7% |
| Decline when first peak 4%+ below second | 16% (199 samples) |
| Decline when first peak >4% above second | 7% (3,210 samples) |
| Benchmark decline after any peak | 10% (median; per-stock range 5%–22%) |
| 2B beat benchmark | 34% of the time overall; 42% (first peak below second) vs 32% (first peak above) |
| Width effect | Peaks ≤ median 10 days apart dropped 7% vs 6% for wider |

Bottoms (14,890 samples, same universe):

| Metric | Value |
|---|---|
| Gain when first valley 4% above second | 43% (175 samples) |
| Gain when first valley 4% below second | 32% (2,439 samples) |
| Benchmark rise after any bottom | 34% average (per-stock range 13%–183%) |
| 2B (first valley above second) beat benchmark | 33% vs 26% (first valley below) |
| Width effect | ≤ 21-day median: 36% (first valley above) vs 31%; wider: 37% vs 31% |

Notable: the pattern "works as Sperandeo says" directionally — a marginal new high/low
that fails produces a bigger move — yet it beats the per-stock benchmark only a minority
of the time (34% tops, 33% bottoms), which Bulkowski calls puzzling. In a wider-bottom
run (59-day median), the first-valley-above advantage flipped (51% vs 54%).

## Trading Tactics

- Primarily a profit-taking / exit-timing tool for swing traders, not a standalone entry.
- 2B top: use it to exit longs promptly after a marginal new high fails; fake moves are common.
- 2B bottom: can get you into a double-bottom trade before confirmation, but failure risk
  is much greater (unconfirmed double bottoms fail 44% of the time).
- Prefer tops where the first peak is below the second and the peaks are close together
  in time; prefer bottoms where the first valley is above the second.
- Insist on the Sperandeo trigger — no drop back below the previous high, no valid 2B.

## Pine Notes

- Feasibility: **moderate**. Needs consecutive `ta.pivothigh`/`ta.pivotlow` tracking;
  pivots confirm `r` bars late, so evaluate R5 only on bars after the second pivot is
  confirmed and fire signals on the trigger-close bar (no repaint).
- The trigger (R5) itself is objective and cheap; the subjective parts are trend context
  (R1) and "failure to carry through", which R6's timeliness window approximates.
- Suggested inputs: pivot length, peak proximity % (R3, default 5%), max peak separation
  (R4), trigger window bars (R6), volume filter on/off (R7), top/bottom/both mode.
- Track `peak1/peak2` (or `valley1/valley2`) in `var` UDTs storing `time`, `bar_index`,
  and price; reset candidates when price moves more than the proximity tolerance away.
